Le dossier contient 4 fichiers Java qui simulent le déplacement d'une reine sur un échiquier.
(Position.java) Définit les coordonnées d'une case (ligne, colonne)
(Piece.java) Classe parent. Vérifie si une case est dans l'échiquier (lignes 1 à 8, colonnes 1 à 8)
(Reine.java) Classe enfant qui hérite de Piece. Redéfinit la méthode (isValidMove) pour appliquer les règles de déplacement de la reine (horizontal, vertical, diagonal) |
(Main.java) Programme principal. Crée une reine, teste un déplacement et affiche le résultat
